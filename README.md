# คุ้มก่อน (prototype)

Prototype เว็บแอปแบบมือถือ (PWA) สำหรับรวมโปรโมชั่นทุกหมวด แปลงความคุ้มเป็นเงินบาท แล้วจัดอันดับเป็นฟีด

- ฟีดจัดอันดับความคุ้ม + แถบ "ใกล้หมดเวลา" พร้อมตัวนับถอยหลัง
- สำรวจตามหมวด ค้นหา และเรียงลำดับ
- เพิ่มโปรเอง: เก็บไว้ดูเอง หรือส่งให้ทุกคนเห็น (สถานะรอตรวจ)
- บันทึกโปร และดูวิธีคิดความคุ้มทีละขั้น
- ช่องโปรสนับสนุนและแบนเนอร์ติดป้ายชัดเจน ไม่มีผลต่ออันดับ

ข้อมูลโปรทั้งหมดเป็นข้อมูลตัวอย่าง ไม่มีเซิร์ฟเวอร์ ข้อมูลของผู้ใช้เก็บใน `localStorage`

## ใช้งาน

```bash
npm install
npm run dev     # เปิดแอป
npm test        # ทดสอบการคิดความคุ้ม
npm run build   # สร้างไฟล์สำหรับ deploy ใน dist/
```

## โครงสร้าง

- `src/lib/value.ts` — สูตรคิดความคุ้มและการจัดอันดับ
- `src/data/` — โปรตัวอย่าง หมวดหมู่ และอัตราแปลงแต้มเป็นบาท
- `src/screens/` — ฟีดคุ้ม, สำรวจ, ของฉัน
- `src/components/` — การ์ดโปร ตัวนับถอยหลัง แผ่นรายละเอียด ฟอร์มเพิ่มโปร
- `src/styles/tokens.css` — สี ฟอนต์ และโหมดมืด
