# คุ้มก่อน (prototype)

Prototype เว็บแอปแบบมือถือ (PWA) สำหรับรวมโปรโมชั่นทุกหมวด แปลงความคุ้มเป็นเงินบาท แล้วจัดอันดับเป็นฟีด

- หน้าแรก: แบนเนอร์ดีลเด็ด แถวหมวดหมู่ แถบ "รีบใช้ก่อนหมดเวลา" พร้อมตัวนับถอยหลัง และรายการโปรที่เรียงได้ตามเงินที่ประหยัดหรือ %
- หน้าแนะนำตอนเปิดครั้งแรก และเลือกแอป/บัตรที่มีเพื่อกรองโปรที่ใช้ได้เลย
- หมวดหมู่: ค้นหาและเรียงลำดับ
- เพิ่มโปรเองแบบ 3 ขั้น: เก็บไว้ดูเอง หรือส่งให้ทุกคนเห็น (สถานะรอตรวจ) แนบรูปได้
- บันทึกโปร ดูวิธีใช้และวิธีคิดความคุ้ม
- ช่องโปรสนับสนุนและแบนเนอร์ติดป้ายชัดเจน ไม่มีผลต่ออันดับ

ข้อมูลโปรทั้งหมดเป็นข้อมูลตัวอย่าง ไม่มีเซิร์ฟเวอร์ ข้อมูลของผู้ใช้เก็บใน `localStorage`

## โลโก้แบรนด์

- แบรนด์ที่มีในชุด [Simple Icons](https://simpleicons.org) ใช้โลโก้จากชุดนั้น ส่วนแบรนด์อื่นแสดงตัวอักษรย่อบนสีแบรนด์
- เพิ่มโลโก้เอง: วางไฟล์ใน `public/brands/` แล้วใส่ชื่อไฟล์ในช่อง `file` ของแบรนด์นั้นใน `src/data/brands.ts`
- โลโก้และชื่อแบรนด์เป็นของเจ้าของแบรนด์ ก่อนเปิดใช้จริงต้องขอสิทธิ์ใช้ผ่านโปรแกรมพาร์ตเนอร์ของแต่ละแบรนด์

## ใช้งาน

```bash
npm install
npm run dev     # เปิดแอป
npm test        # ทดสอบการคิดความคุ้ม
npm run build   # สร้างไฟล์สำหรับ deploy ใน dist/
```

## โครงสร้าง

- `src/lib/value.ts` — สูตรคิดความคุ้มและการจัดอันดับ
- `src/data/` — โปรตัวอย่าง แบรนด์ หมวดหมู่ และอัตราแปลงแต้มเป็นบาท
- `src/screens/` — หน้าแรก, หมวดหมู่, ที่บันทึก, ของฉัน
- `src/components/` — การ์ดโปร ตัวนับถอยหลัง แผ่นรายละเอียด ฟอร์มเพิ่มโปร
- `src/styles/tokens.css` — สี ฟอนต์ และโหมดมืด
